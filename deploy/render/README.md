# JanaSutra API

FastAPI backend for JanaSutra: Civix-Intelligence (civic complaint pipeline with
live YOLOv8 pothole detection via ONNX Runtime). Deployed on Render as a Docker
web service; interactive docs at `/docs`.

This repo is generated from the main project by `deploy/stage_render.sh` —
edit the source project, not this copy.

Environment variables: `DATABASE_URL`, `SECRET_KEY`, `ADMIN_PASSWORD`,
`DEMO_PASSWORD`, `CORS_ORIGINS`.
